# 雙語對照翻譯（Chrome 擴充功能）

用 Claude 把網頁上的英文段落翻成繁體中文，譯文直接顯示在每段原文的正下方。個人自用，不上架。

## 安裝

1. 下載或 clone 這個 repo。
2. 在 Chrome 網址列輸入 `chrome://extensions`，打開右上角的「開發人員模式」。
3. 按「載入未封裝項目」，選這個資料夾。
4. 點工具列上的擴充功能圖示，第一次會自動打開設定頁。
5. 貼上 Claude API 金鑰（到 https://console.anthropic.com/settings/keys 建立），按「測試金鑰」確認可以用，再按「儲存」。

## 進度

- [x] 第 1 步：擴充功能骨架、金鑰設定頁
- [x] 第 2 步：雙語對照翻譯（點工具列圖示開始翻譯，再點一次隱藏或顯示譯文）
- [x] 第 3 步：段落捲到畫面附近才翻、翻過的段落記住不重翻、譯文樣式可選、後來載入的內容自動翻

## 費用

Claude API 依用量計費。只會翻捲到畫面附近的段落，翻過的內容會記在快取裡（設定頁可清除）。設定頁可以選模型：Opus 5.5 品質最好；Haiku 5.5 便宜很多，適合大量翻譯。
